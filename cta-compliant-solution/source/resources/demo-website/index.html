🔄 Token Renewal Demo

This demo shows hybrid path→header token renewal:

  1. Initial request: Uses path token /{TOKEN}/video/sample.m3u8
  2. CloudFront Function: Validates token, strips from path
  3. Near expiry: Function returns renewed token in CTA-Common-Access-Token header
  4. Player switches: Future requests use header token, clean URLs

Benefits: CTA-compliant + streaming player compatible
